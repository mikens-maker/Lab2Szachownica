LABORATORIUM 2 – SZACHOWNICA I MENU

Projekt Java dla Android Studio.

Uruchomienie:
1. Rozpakuj archiwum.
2. W Android Studio wybierz File > Open.
3. Wskaż folder Lab2_Szachownica_Android.
4. Poczekaj na zakończenie synchronizacji Gradle.
5. Uruchom emulator lub podłącz telefon z włączonym debugowaniem USB.
6. Kliknij Run.

Menu:
- Twórca – wyświetla komunikat Toast.
- Wyjście – zamyka aplikację.
- Kolorystyka – zmienia zestaw kolorów szachownicy.

Skalowanie:
Panel.java używa min(getWidth(), getHeight()) i centruje kwadratową planszę.
Dzięki temu szachownica mieści się w dostępnej przestrzeni również po zmianie
orientacji ekranu.

Uwaga:
Projekt jest przygotowany jako kompletna baza źródłowa. Nie zawiera zrzutów
z rzeczywistego emulatora/telefonu, ponieważ wymagają uruchomienia aplikacji
w Android Studio na urządzeniu użytkownika.
